# Breeze 노트

맥북과 갤럭시에서 함께 쓰는 가벼운 노트 앱 (PWA).

- **빠름**: 노트는 기기 안(IndexedDB)에 바로 저장되어 화면이 서버를 기다리지 않습니다. 프레임워크 없이 순수 JS로 만들었습니다.
- **오프라인 동작**: 인터넷이 없어도 쓰고 읽을 수 있고, 다시 연결되면 자동으로 동기화됩니다.
- **동기화**: Supabase 무료 플랜. 바뀐 노트만 주고받고, 다른 기기에는 실시간으로 반영됩니다. 같은 노트를 두 기기에서 고치면 **나중에 수정한 쪽**이 남습니다.
- 기능: 첫 줄이 제목, `#태그`(사이드바에서 태그별 모아보기), 사진(붙여넣기·끌어놓기·📷 버튼, 자동 압축), 체크리스트, 글머리 목록, 소제목, 굵게, 고정, 검색, 삭제 후 실행 취소, 다크 모드, JSON 백업.
- 단축키: `⌘N` 새 노트, `⌘⇧L` 체크리스트, `⌘B` 굵게, `⌘F` 검색.

## 1. 동기화 서버 만들기 (5분, 무료)

1. https://supabase.com 에서 가입하고 **New project**를 만듭니다.
2. 왼쪽 **SQL Editor**에 `supabase.sql` 내용을 전부 붙여넣고 **Run**을 누릅니다. (예전 버전으로 이미 설정했다면 `supabase-photos.sql`만 추가로 실행)
3. **Project Settings → API**에서 `Project URL`과 `Publishable key`(또는 `anon public` 키)를 복사합니다.
4. (선택) **Authentication → Sign In / Providers → Email**에서 "Confirm email"을 끄면 가입 즉시 로그인됩니다. 켜 두면 확인 메일의 링크를 한 번 눌러야 합니다.

## 2. 앱 올리기 (무료 호스팅)

PWA 설치와 휴대폰 접속에는 HTTPS 주소가 필요합니다. 가장 쉬운 방법:

- **Netlify Drop**: https://app.netlify.com/drop 에 이 폴더를 통째로 끌어다 놓기 → 주소가 생깁니다.
- 또는 GitHub Pages, Vercel, Cloudflare Pages 중 아무거나 (빌드 과정 없음, 정적 파일 그대로).

## 3. 기기에 설치

- **맥북 (Chrome)**: 주소창 오른쪽의 설치 아이콘 → 설치. Dock과 Launchpad에 앱으로 들어갑니다.
- **맥북 (Safari)**: 파일 → Dock에 추가.
- **갤럭시 (Chrome 또는 삼성 인터넷)**: 메뉴 → "홈 화면에 추가" / "앱 설치".

각 기기에서 왼쪽 위 동그라미(동기화 점)를 눌러 같은 URL·키·이메일로 로그인하면 끝입니다. 점이 초록색이면 동기화된 상태입니다.

## 로컬에서 실행

```bash
python3 -m http.server 5173
```

http://localhost:5173 을 엽니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html`, `style.css` | 화면 (맥은 2단, 휴대폰은 목록 ↔ 편집 전환) |
| `app.js` | 저장, 편집기, 동기화 |
| `sw.js` | 오프라인 캐시 (새 버전은 다음 실행 때 적용) |
| `supabase.sql` | 서버 테이블, 보안 규칙, 충돌 처리 |
